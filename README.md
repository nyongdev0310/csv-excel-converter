# CSV to Excel Converter

A simple Windows desktop tool that converts raw CSV files into clean Excel files.

## What it does
- Load one or multiple CSV files
- Clean and normalize data (trim spaces, handle empty values, etc.)
- Export to Excel (*.xlsx) with a structured format

## Tech
- C# / .NET
- WinForms or WPF
- File IO, CSV parsing

> This is a sample project for data conversion and automation tasks.
